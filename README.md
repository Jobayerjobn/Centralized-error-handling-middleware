# Centralized Error Handling Middleware (Node.js + Express)

A clean and scalable way to handle errors in Express applications using a centralized middleware approach.

---

## Features

* Custom Error Class (`AppError`)
*  Global Error Handling Middleware
* Clean and consistent API responses
* Production & Development ready structure

---

##  Why Centralized Error Handling?

Instead of writing `try...catch` in every route, this approach:

* Keeps code clean 
* Makes debugging easier 
* Improves scalability 
* Follows industry best practices 

---

## Installation

```bash
git clone https://github.com/your-username/centralized-error-handling.git

```
